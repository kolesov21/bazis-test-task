# Базис

SPA для заметок со списками задач: создание, редактирование, undo/redo и восстановление черновиков. Данные хранятся в браузере.

Стек: Nuxt 4, Vue Composition API, TypeScript strict, Pinia и SCSS. Интерфейс, история изменений и синхронизация с хранилищем реализованы без сторонних библиотек для этих задач.

## Запуск

Требуется Node.js 24.11+ и npm.

```sh
npm ci
npm run dev
```

Приложение доступно на http://localhost:3000.

Production-сборка:

```sh
npm run build
npm run preview
```

Для внешнего размещения нужен HTTPS. Данные привязаны к браузеру и адресу приложения: разные хосты и порты имеют отдельные хранилища.

## Docker

```sh
docker-compose up
```

Для Docker Compose v2:

```sh
docker compose up --build
```

Приложение доступно на http://localhost:3000. База данных и том для заметок не нужны: они сохраняются в браузере посетителя.

## Проверки

```sh
npm run check         # типизация, unit-тесты и production-сборка
npm run format:check  # форматирование
```

Playwright запускает production-сервер на порту 3001. Перед браузерными тестами нужна свежая сборка:

```sh
npx playwright install chromium firefox webkit
npm run build
npm run test:e2e
```

Проекты: `chromium`, `firefox`, `webkit`, `mobile` (эмуляция iPhone 13 в WebKit). Для отдельного проекта: `npm run test:e2e -- --project=chromium`.

## Структура

```text
app/
  pages/          — список заметок и редактор
  components/     — переиспользуемые элементы интерфейса
  composables/    — сессия редактора и подтверждения
  domain/         — модель, валидация, история и хранение
  stores/         — сохранённые заметки и операции с ними
  plugins/        — загрузка и синхронизация между вкладками
  assets/styles/  — общие стили; стили компонентов находятся в scoped-блоках
tests/
  unit/           — Vitest: история, стор и форматы хранения
  e2e/            — Playwright: пользовательские сценарии
```

## Поведение

- Редактор работает с отдельной копией заметки до сохранения. Пустое название и пустой текст задачи блокируют сохранение; заметка без задач допустима.
- История хранит до 50 обратимых операций. Ввод группируется по потере фокуса или паузе 600 мс. Новая правка очищает redo; сохранение и отмена редактирования сбрасывают историю.
- `Ctrl/⌘ + Z` отменяет изменение, `Ctrl/⌘ + Shift + Z` повторяет, `Ctrl/⌘ + S` сохраняет заметку.
- Заметки записываются в `localStorage` при сохранении и удалении. Черновики сохраняются отдельно в `sessionStorage` каждой вкладки; после перезагрузки предлагается восстановление. Оба формата содержат версию схемы.
- Если заметка изменена или удалена в другой вкладке, рабочий текст остаётся в редакторе и доступно «Сохранить как новую». Запись защищена ревизиями и Web Locks; без Web Locks возможны гонки между вкладками.
- Ошибки хранилища показываются пользователю. Повреждённые данные и неизвестные версии схемы не перезаписываются автоматически.
